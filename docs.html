01. ENGINE_OVERVIEW

Fish Vault is a procedural biological synthesis engine and digital taxonomic repository built upon the Swiss-Archival design system. The system synthesizes deterministic biological specimens based on narrative sequences or species names, translating mathematical spline curves and morphological parameters into plotter-ready vector linework.

The underlying synthesis algorithm is adapted from Lingdong Huang's fishdraw, paired with the brutalist archival curation, tactile 300gsm paper aesthetics, format matrix, and embeddable architecture originated in Azzar Budiyanto's Geometry Vault.

PRODUCTION_ENDPOINT

https://fish-vault.glassgallery.my.id

RUNTIME_REQUIREMENTS

Zero external dependencies. Pure Vanilla ES6+.

02. PROCEDURAL_ANATOMY & NARRATIVE_INJECTION_LOGIC

Specimens are algorithmically synthesized through a multi-pass anatomical pipeline. Injected narrative sequences (such as blog post titles, prompts, or article excerpts) establish an immutable deterministic pipeline:

NARRATIVE PROSE → FNV-1a SEED HASH → ACCESSION ID (FV-XX-XXXXXX) → DETERMINISTIC TAXON NAME

01. BODY CURVATURE & PROFILE

Calculates standard length ($SL$) and body depth ($BD$). Curve styles vary between sinusoidal swimming gestures, arcuate postures, and disciform silhouettes.

02. DORSAL & CAUDAL FINS

Generates spine counts, segmented soft-rays, and tail morphology (Forked, Emarginate, Truncate, Rounded, Lunate, Lyretail, or Heterocercal).

03. MERISTIC SCALE CLASSIFICATION

Synthesizes dermal patterns: Cycloid (smooth), Ctenoid (comb-edged), Ganoid (rhombic enamel), and granular placoid tessellations.

04. CEPHALIC STRUCTURE & TAXON SCRIBE

Computes jaw opening, eye diameter, maxillary and mental barbels, dentition, and scribes the derived Latin binomial nomenclature in vector Hershey script.

03. EMBED_MODE_PROTOCOL

Embed mode provides an iframe-optimized, uncluttered view of the specimen plate. It strips away the side matrix and headers, rendering only the specimen plate with transparent or archival background.

IFRAME_SNIPPET

<iframe 
  src="https://fish-vault.glassgallery.my.id/?mode=embed&narrative=The%20Future%20of%20Distributed%20Systems&w=3&h=2" 
  width="600" 
  height="400" 
  frameborder="0" 
  style="border: 1px solid #DDD5C5; border-radius: 4px;">
</iframe>

SUPPORTED URL PARAMETERS

  • mode: Set to embed to strip UI chrome and render pure archival plate.
  • narrative / seed: Blog title, essay prompt, phrase, or binomial taxon string.
  • id: Accession identifier (e.g. FV-82-DHMSR8) for exact specimen recovery.
  • w & h: Aspect ratio dimension ratio (e.g., ?w=3&h=2).
  • render (or mode_render): static (default) or anim (live pen plotter simulation).

Interactive Mode Selector: On the embed itself, an interactive micro-badge in the bottom-right corner allows viewers to switch between STATIC and ANIM playback dynamically.

04. REAL_TIME_CONTROL (POSTMESSAGE API)

Parent web pages can control an embedded Fish Vault iframe in real-time without reloading via the browser postMessage API (featuring protocol parity with Geometry Vault): 

// Method 1: Comprehensive Specimen Update (Geometry Vault Parity)
const vaultIframe = document.querySelector('iframe');

vaultIframe.contentWindow.postMessage({
  type: 'UPDATE_SPECIMEN', // or 'SET_SPECIMEN'
  data: {
    seed: 'Latimeria chalumnae',
    w: 1,
    h: 1,
    mode_render: 'static' // or 'anim'
  }
}, '*');

// Method 2: Granular Triggers
vaultIframe.contentWindow.postMessage({
  type: 'SET_SEED',
  data: { seed: 'Thunnus thynnus' }
}, '*');

vaultIframe.contentWindow.postMessage({
  type: 'SET_MODE',
  data: { mode: 'anim' } // or 'static'
}, '*');

05. VECTOR_SYNTHESIS_&_SMIL_ANIMATION

All Fish Vault outputs are natively generated as continuous vector polylines. Users can export clean standalone SVG plates or animated SMIL vector plates:

  • Clean Vector Plate [ SVG ]: Pure SVG paths wrapped in an archival border with accession ID and 32-bit hash stamps.
  • Animated Plotter [ ANIM SVG ]: Self-contained SMIL animated SVG that simulates physical pen plotter drawing in any web browser without external JavaScript dependencies.
  • High-Resolution Raster [ PNG 300DPI ]: Matte-rendered canvas export featuring authentic 300gsm paper grain noise.

06. ACCESSION_ID & RECONSTRUCTION_LOGIC

Every specimen receives a deterministic accession identifier (e.g., FV-82-DHMSR8). The identifier encodes a 6-character Base34 hash suffix, allowing lossless 100% bidirectional reconstruction:

RECOVERY_PROTOCOL

GET /?id=FV-82-DHMSR8

In the main vault interface, inserting an accession ID into the RECOVER FROM ID input regenerates the exact morphological specimen and its taxonomic Latin name instantly without server state.

07. CMS & WORDPRESS_INTEGRATION_GUIDE

Automate featured article or taxonomy plates by embedding deterministic specimens into WordPress, Ghost, or static site generators using the article title as narrative: 

// WordPress functions.php: Generate custom specimen plate embed for articles
function get_fish_vault_specimen_embed($post_title) {
    $encoded_narrative = urlencode($post_title);
    $url = "https://fish-vault.glassgallery.my.id/?mode=embed&narrative={$encoded_narrative}&w=3&h=2";
    return '<iframe src="' . esc_url($url) . '" width="600" height="400" frameborder="0" style="border:1px solid #DDD5C5; border-radius:4px;" title="Archival Pisces Specimen"></iframe>';
}

08. BROWSER JAVASCRIPT SDK REFERENCE

fishdraw.js exposes the global window.FishDraw object in browser environments and standard module.exports in Node.js: 

// 1. Generate specimen via narrative injection (Narrative -> Seed -> ID -> Taxon)
const specimen = window.FishDraw.generateSpecimen({
    narrative: 'Deep Sea Hydrothermal Ecology',
    width: 600,
    height: 400,
    pad: 30,
    includeLabel: true
});

console.log(specimen.accessionId); // "FV-82-DHMSR8"
console.log(specimen.taxon); // "Aptocebus vadens"
console.log(specimen.metrics.standardLength); // "320 mm"
console.log(specimen.metrics.hashHex); // "0x17B80F83"

// 2. Bidirectional recovery utilities
const hash = window.FishDraw.generateSecureHash('Deep Sea Hydrothermal Ecology');
const id = window.FishDraw.generateSequenceIdentifier(hash);
const recoveredHash = window.FishDraw.recoverHashFromId(id);
const taxon = window.FishDraw.binomen(hash);

// 3. Render clean vector SVG with archival plate stamps
const svgString = window.FishDraw.draw_svg(specimen.polylines, {
    width: 600,
    height: 400,
    stroke: '#2A2520',
    bg: '#EFE9DC',
    specimen: specimen,
    taxon: specimen.taxon
});

// 4. Render animated SMIL pen-plotter SVG
const animSvgString = window.FishDraw.draw_svg_anim(specimen.polylines, 0.005, {
    width: 600,
    height: 400,
    stroke: '#2A2520',
    specimen: specimen,
    taxon: specimen.taxon
});
