01. ENGINE_OVERVIEW

Fish Vault is a procedural biological synthesis engine and digital taxonomic repository built upon the Swiss-Archival design system. The system synthesizes deterministic biological specimens based on narrative sequences or species names, translating mathematical spline curves and morphological parameters into plotter-ready vector linework.

The underlying synthesis algorithm is adapted from Lingdong Huang's fishdraw, paired with the brutalist archival curation, tactile 300gsm paper aesthetics, format matrix, and embeddable architecture originated in Azzar Budiyanto's Geometry Vault.

PRODUCTION_ENDPOINT

https://fish-vault.glassgallery.my.id

RUNTIME_REQUIREMENTS

Zero external dependencies. Pure Vanilla ES6+.

02. PROCEDURAL_ANATOMY & MORPHOMETRIC_LOGIC

Specimens are algorithmically synthesized through a multi-pass anatomical pipeline. Narrative strings are hashed via a bitwise PRNG into deterministic anatomical parameters:

01. BODY CURVATURE & PROFILE

Calculates standard length ($SL$) and body depth ($BD$). Curve styles vary between sinusoidal swimming gestures and arcuate postures.

02. DORSAL & CAUDAL FINS

Generates spine counts, segmented soft-rays, and tail morphology (Forked, Emarginate, Truncate, Rounded, Lunate, or Heterocercal).

03. MERISTIC SCALE CLASSIFICATION

Synthesizes dermal patterns: Cycloid (smooth), Ctenoid (comb-edged), Ganoid (rhombic enamel), and granular placoid tessellations.

04. CEPHALIC STRUCTURE & DENTITION

Computes jaw opening, eye diameter, maxillary and mental barbels, and dentition (dentate with millimeter spines vs. edentulous).

03. EMBED_MODE_PROTOCOL

Embed mode provides an iframe-optimized, uncluttered view of the specimen plate. It strips away the side matrix and headers, rendering only the specimen plate with transparent or archival background.

IFRAME_SNIPPET

<iframe 
  src="https://fish-vault.glassgallery.my.id/?mode=embed&seed=Salmo%20salar&theme=linnaean&w=3&h=2" 
  width="500" 
  height="500" 
  frameborder="0" 
  style="border: 1px solid #DDD5C5; border-radius: 4px;">
</iframe>

SUPPORTED URL PARAMETERS

  • mode: Set to embed to strip UI chrome and render pure archival plate.
  • seed / id: Narrative string, species name, or accession ID.
  • theme: Palette preset (linnaean, cyanotype, challenger, vellum).
  • w & h: Aspect ratio dimension ratio (e.g., ?w=3&h=2).
  • mode_render: Set to anim for live pen plotter simulation or static for vector plate.

04. REAL_TIME_CONTROL (POSTMESSAGE API)

Parent web pages can control an embedded Fish Vault iframe in real-time without reloading via the browser postMessage API (featuring protocol parity with Geometry Vault): 

// Method 1: Comprehensive Specimen Update (Geometry Vault Parity)
const vaultIframe = document.querySelector('iframe');

vaultIframe.contentWindow.postMessage({
  type: 'UPDATE_SPECIMEN', // or 'SET_SPECIMEN'
  data: {
    seed: 'Latimeria chalumnae',
    theme: 'cyanotype',
    w: 1,
    h: 1,
    mode_render: 'static' // or 'anim'
  }
}, '*');

// Method 2: Granular Triggers
vaultIframe.contentWindow.postMessage({
  type: 'SET_SEED',
  data: { seed: 'Thunnus thynnus' }
}, '*');

vaultIframe.contentWindow.postMessage({
  type: 'SET_THEME',
  data: { theme: 'challenger' }
}, '*');

05. PLOTTER_INTEGRATION (AXIDRAW / CNC / G-CODE)

Unlike bitmap graphics, all Fish Vault outputs are natively generated as continuous vector polylines. Clicking [ PLOTTER CSV ] exports raw ordered coordinates: 

# Format: Each line represents a continuous pen-down stroke
# Coordinates: x1,y1;x2,y2;x3,y3...
124.50,45.20;126.10,48.00;129.40,51.80
180.00,82.10;185.30,83.40;192.10,84.90

This coordinate format can be imported into Inkscape (AxiDraw extension), converted to G-code via Python, or fed into laser engravers and physical vector plotters.

06. ACCESSION_ID & RECONSTRUCTION_LOGIC

Every specimen receives a deterministic accession identifier (e.g., FV-25-9AC9). The identifier is derived directly from the 32-bit PRNG seed hash:

RECOVERY_PROTOCOL

GET /?id=FV-25-9AC9

In the main vault interface, inserting an accession ID into the RECOVER FROM ID input regenerates the exact morphological specimen instantly.

07. CMS & WORDPRESS_INTEGRATION_GUIDE

Automate featured article or taxonomy plates by embedding deterministic specimens into WordPress, Ghost, or static site generators: 

// WordPress functions.php: Generate custom specimen plate embed for articles
function get_fish_vault_specimen_embed($post_title) {
    $encoded_title = urlencode($post_title);
    $url = "https://fish-vault.glassgallery.my.id/?seed={$encoded_title}&theme=linnaean&w=16&h=9&mode=embed";
    return '<iframe src="' . esc_url($url) . '" width="100%" height="450" frameborder="0" style="border:1px solid #DDD5C5; background:#EFE9DC;"></iframe>';
}

08. BROWSER JAVASCRIPT SDK REFERENCE

fishdraw.js exposes the global window.FishDraw object in browser environments and standard module.exports in Node.js: 

// 1. Generate specimen with full telemetry
const specimen = window.FishDraw.generateSpecimen({
    seed: 'Thunnus thynnus',
    width: 600,
    height: 400,
    pad: 30,
    includeLabel: true
});

console.log(specimen.accessionId); // "FV-25-9AC9"
console.log(specimen.metrics.standardLength); // "342 mm"
console.log(specimen.polylines); // Array of [[x, y], ...] strokes

// 2. Render clean vector SVG with archival plate stamps
const svgString = window.FishDraw.draw_svg(specimen.polylines, {
    width: 600,
    height: 400,
    stroke: '#2A2520',
    bg: '#EFE9DC',
    specimen: specimen
});

// 3. Render animated SMIL pen-plotter SVG
const animSvgString = window.FishDraw.draw_svg_anim(specimen.polylines, 0.005, {
    width: 600,
    height: 400,
    stroke: '#2A2520',
    specimen: specimen
});
