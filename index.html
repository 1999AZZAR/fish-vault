01. ARCHIVAL_SYNTHESIS_OVERVIEW

The Fish Vault Specimen Vault is a digital synthesis engine and taxonomic archival repository designed for technical minimalism and structural honesty. It facilitates the procedural generation, visualization, and preservation of biological specimens based on narrative input sequences, bridging historical natural history monographs with brutalist digital archiving.

02. PROCEDURAL_ICHTHYOLOGY_LOGIC

By injecting narrative sequences (e.g. blog post titles, essay prompts, narrative excerpts, or taxonomic names) into the matrix, the engine deterministically establishes the synthesis seed via a 32-bit FNV-1a hash. The architecture enforces an immutable pipeline: Narrative → Seed → Accession ID (FV-XX-XXXXXX) → Taxon Name. The derived Latin binomen is scribed directly onto the plate in vector Hershey script, while the seed governs anatomical spline curves, meristic scale classifications, and fin ray distributions. The entire accession can be losslessly recovered bidirectional from its ID.

03. ARCHIVAL_EXPORT_PROTOCOL

Specimens can be exported as clean vector SVG plates, live SMIL animated drawing vectors, or 300DPI canvas PNGs with organic rag paper grain. Adhering to the Swiss-Archival design system, the visual architecture mimics 300gsm matte-printed archival media.

04. EMBED_INTEGRATION_PROTOCOL

Fish Vault functions as a standalone embeddable service. Utilizing the ?mode=embed URL parameter, the interface strips ornamental controls and renders a clean archival plate suitable for iframe embedding, with interactive static/animated mode selection on the embed itself. External parent applications can control the synthesis engine in real-time via the postMessage API.

05. PROGRAMMATIC_ARCHIVAL_ACCESS

The vault provides complete client-side and server-side JavaScript SDK access via window.FishDraw and Node.js. Developers can synthesize specimens, extract morphometric telemetry (Standard Length, Body Depth, Curvature, Scale and Fin Classifications), and generate plotter vectors without external dependencies.
