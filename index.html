01. TAXONOMIC SYNTHESIS

Fish Vault transforms narrative sequences into anatomical parameters via cryptographic PRNG hashing. Each seed deterministically defines body curvature, spine density, meristic scale patterns, and a pseudo-Latin binomen generated using historical Linnaean morphemes.

02. PLOTTER-CENTRIC GEOMETRY

Unlike raster generators, all specimens are synthesized as ordered polyline vector strokes. This ensures zero fidelity loss at any resolution and direct compatibility with CNC pen plotters (e.g. AxiDraw), laser cutters, and vector archival repositories.

03. EMBED & ARCHIVAL PRESERVATION

Specimens can be permanently embedded into digital publications or field journals using the ?mode=embed URL parameter. URL state syncing ensures full reproducibility and deep-linking across research environments.
